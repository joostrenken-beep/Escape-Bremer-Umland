# Gerätetest-Checkliste

Automatisch getestet (bei jedem Push): Code-Prüfung, Punkte, Spielstand, Content-Schema, Rätsel-Logik.
Im Browser (Chromium, iPhone-Größe) durchgespielt: alle 10 Stationen, alle Rätseltypen, Kamera (simuliert), Urkunde.

**Nicht automatisch prüfbar – bitte auf echten Geräten abhaken:**

| Prüfpunkt | iPhone (Safari) | Android (Chrome) |
|---|---|---|
| Link öffnen, „Zum Home-Bildschirm“, startet ohne Browserleiste | ☐ | ☐ |
| Tour „Für offline speichern“, Flugmodus an, App neu öffnen → läuft | ☐ | ☐ |
| Spielstand nach App schließen / Handy neu starten noch da | ☐ | ☐ |
| Vorlesen (Story, Zeugenaussage) – deutsche Stimme | ☐ | ☐ |
| Morse: Ton hörbar, Lampe blinkt (auch im Lautlos-Modus: Lampe) | ☐ | ☐ |
| Richtungspfeil: Standort-Abfrage erscheint, Entfernung plausibel | ☐ | ☐ |
| Kompass: Bewegungssensor-Abfrage (iPhone), Pfeil dreht sich mit | ☐ | ☐ |
| AR am Weyerberg: Kamera startet, Markierung wandert, Hinweis erscheint | ☐ | ☐ |
| Foto-Vergleich Barkenhoff: Kamera + Schieberegler | ☐ | ☐ |
| Kamera geht nach dem Rätsel aus (grüner Punkt / Kamera-Symbol verschwindet) | ☐ | ☐ |
| Karte (online) lädt Kacheln | ☐ | ☐ |
| Urkunde erstellen und teilen (WhatsApp / Fotos sichern) | ☐ | ☐ |
| Lesbarkeit in praller Sonne | ☐ | ☐ |
| Bedienung mit einer Hand (Daumen erreicht Hauptknopf) | ☐ | ☐ |
| VoiceOver / TalkBack: Knöpfe werden vorgelesen | ☐ | ☐ |

Probleme bitte mit Gerät, Betriebssystem-Version und Station notieren.
